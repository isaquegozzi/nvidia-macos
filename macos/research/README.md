# Arquivo de pesquisa GA106Lab

Fontes e documentos importados em 2026-10-05. Consulte o [estado consolidado](../../docs/macos/STATUS-ATUAL.md) antes de interpretar os registros históricos.

Há 25 árvores de fonte, preservadas com os nomes originais. Cada uma tem seu próprio escopo e versão de bundle. READMEs, manifests e relatórios dentro dessas árvores podem descrever estados anteriores ao último trabalho recebido.

Este diretório também reúne os pacotes de pesquisa, modelos offline, registros de ensaios e os documentos iniciais H0/TGM0. O [manifesto](IMPORT-MANIFEST.json) relaciona a origem e os hashes de cada arquivo importado; documentos podem ter caminhos pessoais sanitizados.

Não foram incluídos binários, diretórios de build, backups de EFI, dumps brutos completos da máquina, credenciais ou arquivos de conversas. A cópia original permanece no arquivo local do projeto.

Para executar os sete modelos portáveis verificados no Linux, use `scripts/test-macos-models.sh` a partir da raiz do repositório. Essa seleção não compila nem carrega a extensão de kernel.
